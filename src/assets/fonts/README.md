The music glyphs in `supertuner-music.woff` are derived from Steinberg's Bravura
(https://github.com/steinbergmedia/bravura), under the SIL Open Font License.
The subset contains sharp and flat, mapped to U+266F/U+266D, and is renamed
Supertuner Music as required for derivatives. See LICENSE-Bravura.txt.

`supertuner-mono.woff` is a Latin/number/em-dash subset of DejaVu Sans Mono 2.37,
from the dejavu-fonts-ttf 2.37.3 distribution. See LICENSE-DejaVu.txt.

Both files are self-hosted. The label uses compact fixed letter, accidental and
octave slots, with normal font baseline alignment and no outline compensation.
